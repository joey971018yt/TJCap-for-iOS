## 一、下載與安裝（內建自動更新，安裝一次日後即可於 App 內一鍵升級！）

請直接前往本專案右側的 **[Releases（發布頁面）](../../releases/latest)** 下載：

1. **📦 正式安裝版 App（最推薦）：`JCast-for-iOS-Setup-v1.9.0.exe`**
   - 雙擊執行安裝精靈，自動在**桌面**與**開始選單**建立帶有專屬圖示的 **「JCast for iOS」** App，並自動註冊 DirectShow 虛擬擷取卡與微軟 WHQL 簽章驅動服務。
   - 內建 **GitHub Releases 自動更新功能**：日後有新版本時，App 內點擊 **`⬆️ 升級`** 即可自動驗證 `SHA-256` 並一鍵完成安裝包升級！
2. **📁 免安裝綠色便攜版 App：`JCast-for-iOS-Portable-v1.9.0.zip`**
   - 解壓縮後直接雙擊資料夾內帶專屬圖示的 **`JCast for iOS.exe`** 即可使用（同樣支援便攜版原地一鍵自動更新！）。

> **前置需求**：電腦需安裝微軟市集版 **Apple 裝置 (Apple Devices)** 或 **iTunes**（提供 Apple 原廠手機信任配對服務）。

## 二、30 秒快速開始教學（支援繁中／English 雙語、故障自檢、健康度監測與 OBS 直播）

1. 開啟桌面上的 **「JCast for iOS」** App（啟動時會於背景自動檢查是否有新版更新；可隨時於主設定區右下角 **`🌐 語言 / Language`** 免重啟即時切換 **自動跟隨系統 / 繁體中文 / English**）。
2. 用 USB 線連接 iPhone / iPad、轉好您要直播的橫向或直向畫面、解鎖手機並點擊 **「信任這部電腦」**：
   - App 會自動辨識目前的 **USB 接口與線材速率**（如 `USB 3.2 10Gbps` / `USB 3.0 5Gbps` / `USB 2.0 480Mbps`），並在下拉選單開放對應的**可選最大解析度上限**（開始傳輸後會全程鎖定您選取的解析度，不會在直播途中自動變動）。
3. 選好想要的解析度上限後，點擊 **`🚀 智慧一鍵啟動`** 按鈕：
   - **🩺 智慧故障偵測與一鍵報錯中心**：自動執行 **8 項系統環境自檢**（攔截缺檔、Zadig 驅動衝突、未信任電腦、通道佔用等 `JCAST-E101`～`E503` 異常，且遇 GPU `D3D11VA` 異常時自動無縫降級 CPU 軟解不斷播）；點擊 **`🩺 診斷報錯`** 即可查看雙語逐步排除教學、複製／匯出**自動隱私脫敏報告**或一鍵開啟 GitHub Issue 回報！
   - **📊 即時串流健康度儀表板**：控制台中央深色儀表板即時顯示 **`FPS` 幀率折線圖**、**`Mbps` 碼率與峰值流量**、**`ms` 微秒級解碼與管線延遲** 及 **智慧健康度診斷（點擊第 4 欄可直接開啟診斷中心）**。
   - **🎬 直接預覽／當外接螢幕（免開 OBS）**：點擊 **`🖥 獨立大視窗`**（或雙擊預覽畫面）彈出獨立視窗，按 **`F11`** 切換無邊框全螢幕、**`Tab` / `F3`** 切換全螢幕健康度 HUD、**`Ctrl+T`** 永遠置頂！
   - **📸 一鍵原畫質無損截圖（`F12`）**：隨時點擊 **`📸 原畫質截圖`** 或按 **`F12`**，擷取 **1:1 原始 2K+ 滿版畫質**儲存為無損 PNG（存於 `圖片\JCast Screenshots`，點 `📂 圖庫` 即開），並同步複製到剪貼簿直接 `Ctrl+V` 貼上！
4. **連接 OBS Studio 直播／錄影**：開啟 OBS ➔ 新增「視訊擷取裝置」➔ 選擇 **`JCast for iOS (Video)`**（保持「裝置預設值」即可自動抓滿版原生比例、零黑邊！）；往下捲動勾選「使用自訂音訊裝置」➔ 選擇 **`JCast for iOS (Audio)`**。

## 三、USB 接口速率自動辨識與最大解析度選項分級

> **設計原則**：僅在**開始擷取前**依據偵測到的 USB 接口速率動態開放「可選最大解析度選項」；**一旦開始投影傳輸即全程鎖定所選解析度，絕不在傳輸途中動態切換**，確保直播畫布穩定不閃爍。

| 偵測到的 USB 接口／線材速率 | 開放之最高可選解析度上限 | 可選項目說明 |
| :--- | :--- | :--- |
| **⚡ USB 3.x (`5 / 10 / 20 Gbps`)** | **最高 `3840p` 無上限** | 解鎖 `🌟 原生極限無上限 (3840p)`（完整釋放 iPhone Pro Max `2868×1320`、iPad Pro `2752×2064`），並保留 `2560p` / `1920p` / `1280p` 及固定 16:9 畫布供自由選取 |
| **🔌 USB 2.0 (`480 Mbps`)**<br/>*(Lightning 或一般 USB-C 充電線)* | **最高 `2K (2560p)`** | 自動隱藏超負荷的 `3840p` 選項，提供 `💎 2K 高畫質上限 (2560p)`、`✨ 1080p 穩定推薦 (1920p)`、`⚡ 720p (1280p)` 與固定 16:9 畫布 |
| **⚠️ USB 1.1 (`1.5 / 12 Mbps`)** | **最高 `720p (1280p)`** | 僅開放 `⚡ 720p (1280p)`、`📱 540p (960p)` 與固定 `1280×720` 畫布，避免低速集線器卡頓斷流 |

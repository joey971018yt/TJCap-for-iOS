# iOS USB 通用有線虛擬擷取卡 (`ios-usb-vcam`) — Windows 10 / 11

純 C++20 打造的 **Windows 10 / 11 iPhone / iPad 有線 USB 低延遲虛擬擷取卡（2K+ 原生自適應比例視訊 + 48kHz 無損音訊）**，附帶 **一鍵智慧圖形化控制台 (`ios_vcam_gui.exe`)**。  
透過 Apple 底層 QuickTime / Valeria (`SubClass 0x2A`) 有線螢幕鏡像協定，免購買實體擷取卡、免越獄、免安裝手機端 App、免開啟 Windows 測試模式、**全程免打指令**，即可將 iPhone / iPad 畫面依機型真實比例（如 iPhone `19.5:9` 最高達 `2868×1320` 2.8K@60fps、iPad `4:3` / `1.44:1` 最高達 `2752×2064`）**滿版零黑邊**直接輸入 **OBS Studio、Discord、Zoom、Teams、WebRTC 瀏覽器**！

---

## 一、超簡單「一鍵啟動」教學（全程圖形介面、免打指令）

1. **前置準備**：
   - Windows 10 / 11 (x64) 電腦安裝 **Apple 裝置 (Apple Devices)** 或 **iTunes**（提供 Apple 原廠 USB 信任配對服務）。
   - 下載本專案右上角綠色 **`<> Code`** ➔ **`Download ZIP`** 並完整解壓縮。
2. **雙擊開啟控制台**：
   - 直接雙擊根目錄的 **`點我啟動_iOS擷取卡控制台.bat`**（或雙擊 `dist-win64\ios_vcam_gui.exe`）。
3. **點擊一顆按鈕自動完成所有步驟**：
   - 用 USB 線接上 iPhone / iPad、切換好手機橫向或直向畫面、解鎖並按 **「信任這部電腦」**。
   - 點擊視窗中央的 **`🚀 智慧一鍵啟動`** 按鈕：
     - 程式會自動完成 DirectShow 擷取卡註冊與微軟 WHQL 簽章 `libusb0` 過濾層掛載，接著**自動以裝置原生 2K+ 解析度與真實比例開始投影**！
     - 下方日誌視窗還會即時顯示目前的**原生解析度比例**與**真實 USB H.264 碼率 (`Mbps`)**。
4. **在 OBS Studio 取得滿版 2K+ 原生比例畫面**：
   - 開啟 OBS Studio ➔ 新增「視訊擷取裝置」➔ 裝置選擇 **`iOS USB Capture Card (Video)`**。
   - 「解析度/FPS 類型」保持 **「裝置預設值」**，OBS 就會自動抓到您當前 iPhone / iPad 的原生 2K+ 解析度與真實長寬比（完全滿版無黑邊！若先開了 OBS 才插手機，點一下「停用 ➔ 啟用」即會自動刷新比例）。
   - 往下捲動勾選「使用自訂音訊裝置」➔ 選擇 **`iOS USB Capture Card (Audio)`**。

## 二、4 種畫質與比例模式（可於控制台下拉切換）

| 模式名稱 | 命令列參數 | 行為說明 |
| :--- | :--- | :--- |
| **🌟 2K+ 原生自適應比例（預設）** | `--res native` | 自動依連接的 iPhone (`19.5:9` / `16:9`) 或 iPad (`4:3` / `3:2`) 吐出最高 **2.8K@60fps** 原生點對點滿版畫面，零黑邊、畫質最銳利 |
| **✨ 1080p 自適應比例** | `--res native1080` | 維持機型真實長寬比（如 iPhone `1920×886`、iPad `1920×1440`）滿版零黑邊，同時降低舊電腦編碼負載 |
| **🖥 固定 2K 16:9 畫布** | `--res 1440p` | 固定輸出 `2560×1440` 16:9 畫布，直播途中任意旋轉手機直橫屏會自動等比縮放補黑邊 |
| **🖥 固定 1080p 16:9 畫布** | `--res 1080p` | 固定輸出 `1920×1080` 16:9 畫布，適合傳統視訊會議軟體 |

## 三、完整移除方式

開啟 `ios_vcam_gui.exe` 點擊 **`🗑 完整移除`** 按鈕（或執行 `dist-win64\uninstall_all_admin.ps1`），即可一鍵移除 Apple 複合裝置上的 `libusb0` UpperFilter 並反註冊 DirectShow 虛擬視訊與音訊擷取卡。
